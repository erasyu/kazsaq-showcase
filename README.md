# KazSaq Showcase

Публичная витрина концепт-демо для клиентов KazSaq dev team.

- Хаб команды с liquid bulge tabs
- Демо: Dala Coffee, Aru Beauty
- Редактор «Под себя» (имя, цвет, город, телефон, WhatsApp) → параметры в URL

## Локально

```bash
npm install
npm run dev
```

## GitHub Pages

```bash
npm run build
npm run deploy
```

Сайт: `https://erasyu.github.io/kazsaq-showcase/`
